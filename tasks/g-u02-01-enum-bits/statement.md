# Извлеки код enum class

<!-- паспорт: type=Т10 minutes=5 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Дан Access с базовым типом unsigned: read=1, write=2, execute=4. Верни его числовой код через std::to_underlying. Стенд может передать комбинацию битов от 0 до 7; менять её нельзя. Пример: Access::write → 2. Сравнение, преобразование к bool и печать имени не заменяют извлечение кода.

## Зачем
Освоить явное преобразование scoped enum средствами C++23.

## Вход и выход
```cpp
unsigned access_bits(Access value);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Как вернуть числовой код значения enum class Access : unsigned, сохранив любую комбинацию битов?

## Шаги
1. Сопоставь Access::write с его базовым типом.
2. В access_bits проверь результат std::to_underlying.
3. Проверь комбинацию read и execute и нулевой код.

## Готово, когда
Все коды 0…7 сохранены без потери битов. Публичные проверки подтверждают эти свойства.
