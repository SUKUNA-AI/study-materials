# Разбери и сохрани пару ключ–значение

<!-- паспорт: type=Т10 minutes=20 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Разбери ровно один знак =. Удали только ASCII-пробелы по краям ключа и значения. Пустой ключ, отсутствие или повтор = дают nullopt; пустое значение разрешено. Верни две собственные строки, которые переживут исходник. Длина до 1024 байт, внутренний NUL — обычный байт. Пример: " key = value " → {"key","value"}.

## Зачем
Собрать несколько знакомых действий в одну функцию и проверить границы контракта.

## Вход и выход
```cpp
std::optional<std::pair<std::string,std::string>> parse_assignment(std::string_view text);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Сколько байт в допустимом значении строки "x="?

## Шаги
1. Отметь единственный знак = в key = value.
2. В parse_assignment раздели структуру и обрезку краёв.
3. Проверь пустое значение и два знака =.

## Готово, когда
Ровно один разделитель; ключ непуст; обе строки собственные. Публичные проверки подтверждают эти свойства.
