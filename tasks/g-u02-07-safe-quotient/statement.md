# Раздели с явным отказом

## Коротко
Верни целочисленное частное либо nullopt, если делитель равен нулю или точное частное не представимо в int32. Округление обычное для целочисленного деления C++ — к нулю. Пример: -7 / 2 → -3. Все входы int32. Не выполняй потенциально недопустимое деление до проверки.

## Зачем
Выразить отказ значением и исключить недопустимую операцию.

## Вход и выход
```cpp
std::optional<int> quotient(int numerator, int denominator);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Чему равно целочисленное частное -7 / 2 по контракту?

## Шаги
1. Предскажи частное для −7 и 2.
2. В quotient перечисли недопустимые деления до вычисления.
3. Проверь нулевой делитель и INT_MIN/−1.

## Готово, когда
Недопустимые входы дают nullopt без UB; знак округлён к нулю. Публичные проверки подтверждают эти свойства.
