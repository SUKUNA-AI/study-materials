# Ограничь значение отрезком

<!-- паспорт: type=Т10 minutes=5 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Верни ближайшее к value значение внутри [lo, hi]. При lo ≤ value ≤ hi ответ равен value. Границы упорядочены; допустим любой int32. Не вычисляй разность границ: она может не помещаться в int. Пример: value=11, lo=0, hi=10 → 10. Напиши ветви самостоятельно, без std::clamp.

## Зачем
Написать взаимоисключающие ветви без лишней арифметики.

## Вход и выход
```cpp
int clamp_value(int value, int lo, int hi);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Что вернётся при value=4, lo=4, hi=4?

## Шаги
1. Расположи value слева, внутри и справа от [lo,hi].
2. В clamp_value опиши возврат для каждой области.
3. Проверь совпавшие границы и крайние int32.

## Готово, когда
Внутреннее значение сохранено; внешнее прижато к ближайшей границе. Публичные проверки подтверждают эти свойства.
