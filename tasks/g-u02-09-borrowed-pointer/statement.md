# Прочитай заимствованный массив

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Верни сумму count чисел через const int*. При count>0 доступны ровно count элементов; при count=0 data может быть nullptr. До 1024 элементов int32. Не освобождай и не изменяй чужую память; верни int64. Пример: {3,-2,4} → 5. Указатель сам не сообщает длину массива.

## Зачем
Различать доступ к памяти и владение памятью.

## Вход и выход
```cpp
std::int64_t sum_pointer(const int* data, std::size_t count);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Что гарантирует контракт sum_pointer(data, count) при count=0?

## Шаги
1. Различи адрес data и число count.
2. В sum_pointer определи границу чтения заимствованной памяти.
3. Проверь nullptr при count=0.

## Готово, когда
Читается ровно count чисел; память не меняется и не освобождается. Публичные проверки подтверждают эти свойства.
