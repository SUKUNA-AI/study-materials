# Раздели владение одним объектом

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Верни два shared_ptr на тот же объект, которым владеет owner. Не создавай копии числа. Пустой вход даёт два пустых указателя. Пример: после создания пары и удаления исходного владельца изменение числа через первый указатель видно через второй. Вызов однопоточный; счётчик владельцев наблюдается только в заранее определённых точках стенда.

## Зачем
Проверить совместное владение без смешения его с копированием данных.

## Вход и выход
```cpp
std::array<std::shared_ptr<int>, 2> share_twice(const std::shared_ptr<int>& owner);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Сколько владельцев у непустого объекта сразу после возврата пары, пока исходный ещё жив?

## Шаги
1. Нарисуй владельцев одного общего числа.
2. В share_twice различи общий объект и копии числа.
3. Убери исходного владельца и измени число через один результат.

## Готово, когда
Оба результата видят один объект; пустой вход даёт два пустых. Публичные проверки подтверждают эти свойства.
