# Циклически переставь трёх владельцев

<!-- паспорт: type=Т10 minutes=20 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Массив содержит ровно три unique_ptr<int>, включая пустые. Выполни один поворот вправо: новый порядок — старый [2],[0],[1]. Объекты int остаются по прежним адресам; выделять память и копировать значения нельзя. Пример: {1,2,3} → {3,1,2}. Проверь адреса, а не только числа: три одинаковых числа не доказывают перенос владельцев.

## Зачем
Собрать несколько знакомых действий в одну функцию и проверить границы контракта.

## Вход и выход
```cpp
void rotate_owners(std::array<std::unique_ptr<int>,3>& owners);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
На каком индексе окажется прежний owners[0]?

## Шаги
1. Подпиши старые адреса позициями 0,1,2.
2. В rotate_owners проследи новый порядок адресов.
3. Проверь пустые элементы и три равных числа.

## Готово, когда
Адреса повернуты вправо; выделений нет. Публичные проверки подтверждают эти свойства.
