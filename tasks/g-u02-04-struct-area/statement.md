# Посчитай площадь структуры

<!-- паспорт: type=Т10 minutes=5 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Rect содержит width и height — числа от 0 до 10⁹. Верни площадь в int64, не меняя структуру. Пример: {3,5} → 15. Нулевая сторона даёт нулевую площадь. Учитывай тип самого умножения: широкий возвращаемый тип не исправит уже выполненное переполнение int.

## Зачем
Читать поля структуры и управлять типом арифметики.

## Вход и выход
```cpp
std::int64_t area(Rect rect);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Почему return rect.width * rect.height в функции с результатом int64 ошибочен для сторон до 10⁹?

## Шаги
1. Оцени порядок площади при сторонах 10⁹.
2. В area проследи тип операндов умножения.
3. Проверь нулевую сторону и две максимальные.

## Готово, когда
Большая площадь представима; Rect не изменён. Публичные проверки подтверждают эти свойства.
