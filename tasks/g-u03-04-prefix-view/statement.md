# Сними один префикс без копии

<!-- паспорт: type=Т10 minutes=5 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Если text начинается с prefix, верни представление оставшегося хвоста; иначе исходное представление. Снять prefix разрешено ровно один раз. Новую строку не создавай. Длины до 1024; оба аргумента живут во время вызова, владелец text живёт и после него. Пример: "pre-pre-x", "pre-" → view на "pre-x" со смещением 4.

## Зачем
Менять границы представления, не создавая нового владельца.

## Вход и выход
```cpp
std::string_view remove_prefix_once(std::string_view text, std::string_view prefix);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Что вернёт remove_prefix_once для text="abab" и prefix="ab"?

## Шаги
1. Отметь снятый участок в pre-pre-x.
2. В remove_prefix_once сохрани связь с исходным владельцем.
3. Проверь отсутствие префикса и пустой prefix.

## Готово, когда
Снят максимум один префикс; возвращён view внутрь text. Публичные проверки подтверждают эти свойства.
