# Отрицательное значение заменяем нулём

<!-- паспорт: type=Т02 minutes=15 place="дом или ноут" check=judge level=supported -->

## Коротко
Собери функцию из двух готовых строк: отрицательное число становится нулём, остальные не меняются.

## Зачем
Вспоминаем условие и ранний возврат без одновременной борьбы с синтаксисом, контейнерами и сборкой.

## Вход и выход
```cpp
int nonnegative(int value);
```
Вход — любое значение `int`. Выход — `0`, если вход отрицателен; иначе исходное число. Примеры: `-3 → 0`, `7 → 7`. Скобки и заголовок функции уже готовы. Новые строки писать не нужно.

## Проверь, что понял
Что вернёт функция для value = 0?

## Шаги
1. Открой редактор на странице. Прочитай условие и ответь на вопрос выше; затем начни работу.
2. Поставь проверку отрицательного значения перед безусловным возвратом. Отбрось две ловушки.
3. Проверь мысленно отрицательный вход, ноль и положительный вход. Отправь решение кнопкой на странице.

## Готово, когда
Открытые и скрытые проверки пройдены. Ты можешь своими словами объяснить граничный случай, а не только показать зелёный вердикт.
