# Отличи отсутствующее число от нуля

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Верни содержимое optional, если оно присутствует; иначе fallback. Ноль и отрицательное число — полноценные значения. Во входе судьи null означает отсутствие. Пример: value=0, fallback=9 → 0. Не разыменовывай пустой optional и не используй само число как признак присутствия.

## Зачем
Применить optional без потери допустимых значений.

## Вход и выход
```cpp
int choose_value(std::optional<int> value, int fallback);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Чему равен результат при value=0, fallback=17?

## Шаги
1. Различи value=0 и отсутствие value.
2. В choose_value проверяй присутствие optional.
3. Проверь отрицательное значение и пустой optional.

## Готово, когда
Fallback используется только при отсутствии. Публичные проверки подтверждают эти свойства.
