# Разверни копию, сохрани исходник

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Верни новый вектор с элементами в обратном порядке. Исходный вектор не меняй; длина от 0 до 1024. Напиши обратный индексный цикл без reverse и обратных итераторов. Пример: {1,2,3} → {3,2,1}. Не начинай беззнаковый индекс с size()-1 для пустого входа.

## Зачем
Писать обратный обход без беззнакового ухода за границу.

## Вход и выход
```cpp
std::vector<int> reverse_copy(const std::vector<int>& values);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Почему обратный цикл с беззнаковым индексом, начатым с values.size() - 1, опасен для пустого вектора?

## Шаги
1. Сопоставь индексы входа и выхода для трёх чисел.
2. В reverse_copy сохрани исходный вектор.
3. Проверь пустой и одноэлементный вход.

## Готово, когда
Порядок обращён; исходник прежний; пустой вход безопасен. Публичные проверки подтверждают эти свойства.
