# Разобрать лимит без исключений

*Реализуй (Т10) · задача дня U04, Ср · судья, 25 тестов · уровень: самостоятельно*

## Коротко
Напиши `parse_budget(text)`: разбери строку цифр в число от 0 до 1 048 576 или верни ошибку значением `std::expected`, без исключений.

## Зачем
Неверный параметр запуска — ожидаемая ошибка: обёртка ядра возвращает её значением, а не бросает.

## Вход и выход
```cpp
enum class ParseError { empty, format, range };  // в solution.h
inline std::expected<std::uint32_t, ParseError> parse_budget(std::string_view text);
```
- Разрешены только ASCII-цифры; ведущие нули допустимы. Строка — до 128 байт.
- Порядок строгий: пустая → `empty`; любой нецифровой байт → `format`; число больше 1 048 576 → `range`.
- Преобразуй через `std::from_chars`. Исключения не бросай.

| `text` | ответ |
|---|---|
| `"128"` | `128` |
| `"12x"` | `format` |
| `"1048577"` | `range` |

## Проверь, что понял
Какую ошибку вернёт `parse_budget("99999999999999999999x")`?
