# Инициализируй весь динамический массив

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Создай массив count чисел: элемент i равен start+i. count∈[0,1024], start∈[−100000,100000], переполнения суммы нет. Нулевой размер даёт nullptr. Пример: count=3, start=5 → {5,6,7}. Используй массивную специализацию unique_ptr и явный цикл; не читай неинициализированную память.

## Зачем
Совместить размер выделения, диапазон индексов и инициализацию элементов.

## Вход и выход
```cpp
std::unique_ptr<int[]> make_ramp(std::size_t count, int start);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Какой способ создать владеющий массив из count чисел корректен?

## Шаги
1. Предскажи три элемента при start=5.
2. В make_ramp проверь инициализацию всех элементов.
3. Проверь count=0 и count=1024.

## Готово, когда
Нулевой размер пуст; каждый элемент соответствует своей позиции. Публичные проверки подтверждают эти свойства.
