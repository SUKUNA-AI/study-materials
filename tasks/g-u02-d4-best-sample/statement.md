# Выбери лучший допустимый образец

<!-- паспорт: type=Т10 minutes=20 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Sample содержит id, value и valid; элементов до 1024, id различны. Среди valid=true выбери наибольший value, при равенстве — наименьший id. Верни optional с id, а не value. Если допустимых нет, верни nullopt. Отрицательные value и id=0 допустимы. Пример: {(5,-1,true),(2,-1,true)} → 2. Сортировка не нужна.

## Зачем
Собрать несколько знакомых действий в одну функцию и проверить границы контракта.

## Вход и выход
```cpp
std::optional<int> best_sample(const std::vector<Sample>& samples);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Какой ID выигрывает при одинаковой оценке у ID 7 и 3?

## Шаги
1. Выдели допустимые записи с равными value.
2. В best_sample проверь правило выбора по id при ничьей.
3. Проверь id=0 и все valid=false.

## Готово, когда
Выбран id, не value; ничья разрешена минимальным id. Публичные проверки подтверждают эти свойства.
