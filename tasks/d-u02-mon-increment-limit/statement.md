# Изменяем число через ссылку

<!-- паспорт: type=Т08 minutes=20 place="дом или ноут" check=judge level=supported -->

## Коротко
Дополни готовую функцию: увеличь число на один, только если оно меньше предела.

## Зачем
Проверяем одно умение: отличать изменение копии от изменения исходного объекта через ссылку.

## Вход и выход
```cpp
void increment_if_below(int& value, int limit);
```
Параметр `value` — ссылка на число вызывающей стороны. `limit` задаёт предел. При `value < limit` увеличь число ровно на один; иначе ничего не делай. Примеры: `(2,5) → 3`, `(5,5) → 5`. Оба параметра могут принимать любые значения `int`.

## Проверь, что понял
Какое значение останется у value после вызова с value = 4 и limit = 4?

## Шаги
1. Открой задачу в редакторе. Перед началом перечитай разобранный пример со ссылкой в уроке.
2. Внутри готового тела допиши только условие и изменение value. Не меняй тип параметра.
3. Проверь случаи ниже предела, на пределе и выше. Сдай файл без main через кнопку отправки.

## Готово, когда
Открытые и скрытые проверки пройдены. Ты можешь своими словами объяснить граничный случай, а не только показать зелёный вердикт.
