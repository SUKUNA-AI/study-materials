# Режим и необязательное значение

<!-- паспорт: type=Т10 minutes=20 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Mode::disabled всегда даёт nullopt. fixed возвращает заданное неотрицательное значение, иначе nullopt. automatic возвращает заданное неотрицательное значение, иначе резерв 8. Только три перечисленных значения enum допустимы. Ноль отличается от отсутствия. Пример: automatic + nullopt → 8; fixed + 0 → 0. Сначала заполни таблицу трёх режимов и трёх состояний значения.

## Зачем
Собрать несколько знакомых действий в одну функцию и проверить границы контракта.

## Вход и выход
```cpp
std::optional<int> selected_limit(Mode mode, std::optional<int> supplied);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Чем selected_limit(Mode::fixed, 0) отличается от selected_limit(Mode::fixed, nullopt)?

## Шаги
1. Составь таблицу режимов и состояний supplied.
2. В selected_limit раздели отсутствие и отрицательное число.
3. Проверь fixed+0 и automatic+nullopt.

## Готово, когда
Каждая строка таблицы выполняется; ноль сохранён. Публичные проверки подтверждают эти свойства.
