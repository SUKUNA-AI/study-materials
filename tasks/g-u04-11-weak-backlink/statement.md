# Свяжи узлы без цикла сильного владения

<!-- паспорт: type=Т10 minutes=15 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Даны разные узлы или пустые указатели. При двух непустых узлах parent должен владеть child через поле child, а child наблюдать parent через weak-поле parent. Если хотя бы одного узла нет, ничего не делай. Поля до вызова пусты. После уничтожения внешних владельцев оба узла должны уничтожиться. Объявление Node уже готово; тип обратного поля не меняй.

## Зачем
Рисовать граф владения и отделять обратную связь от владения.

## Вход и выход
```cpp
void link_nodes(const std::shared_ptr<Node>& parent, const std::shared_ptr<Node>& child);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Почему обратное поле parent должно быть weak_ptr, а не shared_ptr?

## Шаги
1. Нарисуй сильное прямое и слабое обратное ребро.
2. В link_nodes проверь заранее объявленные типы полей.
3. Проверь пустой узел и уничтожение внешних владельцев.

## Готово, когда
Parent удерживает child; оба узла в конце уничтожены. Публичные проверки подтверждают эти свойства.
