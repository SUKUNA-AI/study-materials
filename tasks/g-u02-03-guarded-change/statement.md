# Измени значение только при успехе

<!-- паспорт: type=Т10 minutes=5 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Попробуй прибавить delta к value. Если математический результат вне [0,cap], верни false и оставь value прежним. Иначе сохрани результат и верни true. cap≥0, исходный value∈[0,cap], delta — любой int32. Пример: value=2, delta=-3, cap=10 → false, value остаётся 2. Проверка должна происходить до сужения результата.

## Зачем
Связать проверку контракта с неизменностью состояния на отказе.

## Вход и выход
```cpp
bool try_delta(int& value, int delta, int cap);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Как безопасно проверить, что value + delta остаётся в [0, cap]?

## Шаги
1. Запиши value до неудачного изменения 2 на −3.
2. В try_delta отдели вычисление кандидата от изменения ссылки.
3. Проверь INT_MIN, INT_MAX и точную границу cap.

## Готово, когда
При отказе value прежний; успешный результат внутри [0,cap]. Публичные проверки подтверждают эти свойства.
