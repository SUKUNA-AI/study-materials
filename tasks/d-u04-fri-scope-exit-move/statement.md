# Один выход — одно освобождение

*Найди баг (Т05) · задача дня U04, запас (Пт) · судья, 16 тестов · уровень: самостоятельно*

## Коротко
Почини класс `ScopeExit` в заготовке: после перемещения действие уборки выполняется дважды.

## Зачем
Защитник области (scope guard) освобождает ресурс GPU ровно один раз — даже когда его передают между функциями.

## Вход и выход
```cpp
class ScopeExit {  // определи в solution.cpp
public:
  explicit ScopeExit(std::function<void()> fn);
  ScopeExit(ScopeExit&& other) noexcept;
  void dismiss() noexcept;
  ~ScopeExit() noexcept;  // выполняет непустое активное действие
};
```
- После `dismiss()` действие отменено. Копирование и оба присваивания запрещены.
- Перемещение передаёт действие и активность; источник становится неактивным. Отменённый guard остаётся отменённым.

| сценарий | запусков действия |
|---|---|
| создать, переместить, выйти | 1 |
| создать, переместить, отменить новый, выйти через исключение | 0 |

## Проверь, что понял
Guard `first` отменён через `dismiss()`, затем перемещён в `second`. Сколько раз выполнится действие при выходе?
