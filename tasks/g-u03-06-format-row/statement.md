# Выровняй два столбца

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Собери строку через std::format: имя выровнено влево в поле шириной 8, затем ровно один разделительный пробел, затем число вправо в поле минимальной ширины 5. Перевода строки нет. Имя ASCII, до 8 байт; число int32. Более длинное число не обрезай. Пример результата для name="cpu", count=3 показан открытым тестом с точными пробелами.

## Зачем
Различать минимальную ширину поля, разделитель и направление выравнивания.

## Вход и выход
```cpp
std::string format_row(std::string_view name, int count);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Что произойдёт, если число в format_row длиннее поля минимальной ширины 5?

## Шаги
1. Посчитай пробелы для имени cpu и числа 3.
2. В format_row различи ширину поля и разделитель.
3. Проверь отрицательное число шире пяти символов.

## Готово, когда
Ширины минимальные; число не обрезано; перевода строки нет. Публичные проверки подтверждают эти свойства.
