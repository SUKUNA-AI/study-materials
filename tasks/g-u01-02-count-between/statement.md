# Посчитай значения внутри границ

<!-- паспорт: type=Т10 minutes=5 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Посчитай элементы замкнутого отрезка [lo, hi]. Гарантируется lo ≤ hi; все значения имеют тип int32, длина до 1024. Повторы считаются отдельно. Пример: {1,2,3,4}, lo=2, hi=3 → 2. Ничего не сортируй и не меняй во входе.

## Зачем
Отличать включённые границы и логическое И от ИЛИ.

## Вход и выход
```cpp
std::size_t count_between(const std::vector<int>& values, int lo, int hi);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Сколько раз учитывается значение 3 во входе {3,3}, если lo=hi=3?

## Шаги
1. Обведи значения на обеих границах [2,3].
2. В count_between отдели проверку попадания от счётчика.
3. Проверь lo=hi, повторы и пустой вход.

## Готово, когда
Обе границы включены; каждый повтор посчитан отдельно. Публичные проверки подтверждают эти свойства.
