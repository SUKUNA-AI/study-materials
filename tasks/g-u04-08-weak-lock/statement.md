# Прочитай наблюдаемый объект через lock

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Верни число наблюдаемого объекта либо nullopt, если объект уже уничтожен или weak_ptr пуст. Создай временного владельца через lock и читай через него. Пример: живой объект со значением 0 → присутствующий 0; после уничтожения последнего shared_ptr → отсутствие. Не считай отдельный expired() разрешением разыменовать объект без удержания владельца.

## Зачем
Связать безопасный доступ со временем жизни сильного владельца.

## Вход и выход
```cpp
std::optional<int> weak_value(const std::weak_ptr<int>& observer);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Как безопасно прочитать значение через weak_ptr?

## Шаги
1. Сравни наблюдателя до и после удаления последнего владельца.
2. В weak_value удерживай временное владение при чтении.
3. Проверь живое значение 0 и истёкшую ссылку.

## Готово, когда
Живое число возвращено; истёкшее даёт nullopt. Публичные проверки подтверждают эти свойства.
