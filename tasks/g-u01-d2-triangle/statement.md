# Проверь и классифицируй треугольник

<!-- паспорт: type=Т10 minutes=20 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Три стороны — произвольные int32. Верни 0, если треугольник не существует; 1 для разностороннего, 2 для равнобедренного, 3 для равностороннего. Равносторонний имеет приоритет над равнобедренным. Сумма двух сторон должна вычисляться без переполнения. Пример: 1,2,3 → 0; 2,2,3 → 2. Проверь все три неравенства, нулевую сторону и перестановку сторон.

## Зачем
Собрать несколько знакомых действий в одну функцию и проверить границы контракта.

## Вход и выход
```cpp
int triangle_kind(int a, int b, int c);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Как правильно проверять неравенство треугольника для сторон — произвольных int32?

## Шаги
1. Сравни тройки (1,2,3) и (2,2,3).
2. В triangle_kind раздели существование и классификацию.
3. Проверь нулевую сторону, перестановку и INT_MAX.

## Готово, когда
Вырожденные тройки отвергнуты; равносторонность имеет приоритет. Публичные проверки подтверждают эти свойства.
