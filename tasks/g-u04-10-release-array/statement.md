# Передай массив через границу сырого API

<!-- паспорт: type=Т10 minutes=15 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Верни прежний адрес массива и сделай owner пустым, не удаляя массив. Новый владелец в стенде принимает указатель и затем освобождает его через массивную форму. Пустой вход даёт nullptr. Пример: владелец {1,2,3} → тот же адрес у получателя, исходный owner пуст. Не используй reset: объект должен пережить передачу.

## Зачем
Отличить get, release и reset на границе передачи владения.

## Вход и выход
```cpp
int* hand_out(std::unique_ptr<int[]>& owner);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Какой вызов отдаёт адрес массива, не удаляя его, и оставляет owner пустым?

## Шаги
1. Запиши адрес массива перед передачей.
2. В hand_out различи передачу и уничтожение.
3. Проверь пустой owner и чтение получателем.

## Готово, когда
Адрес сохранён; исходный владелец пуст; массив ещё существует. Публичные проверки подтверждают эти свойства.
