# Обменять пакет целиком

*Реализуй (Т10) · задача дня U03, Пн · судья, 18 тестов · уровень: самостоятельно*

## Коротко
Напиши свободную функцию `swap` для `Packet`: обменяй метку и массив целиком.
Блоки памяти массивов должны поменяться владельцами без копирования элементов.

## Зачем
Обмен (swap) — основа безопасного присваивания у владельцев буферов, например у обёртки над памятью GPU.

## Вход и выход
```cpp
struct Packet { int tag; std::vector<int> values; };  // уже в solution.h
inline void swap(Packet& a, Packet& b) noexcept;
```
- Массивы — до 1000 элементов. Самообмен `swap(a, a)` допустим и ничего не меняет.
- Новую память не выделяй, элементы не копируй.

| до | после `swap(a, b)` |
|---|---|
| `a = {1, [7]}`, `b = {-2, [3, -2, 3]}` | `a = {-2, [3, -2, 3]}`, `b = {1, [7]}` |

## Проверь, что понял
Сколько элементов скопирует верный `swap`, если в каждом пакете по 1000 элементов?
