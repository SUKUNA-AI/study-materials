# Проверяемый доступ без потери const

*Реализуй (Т10) · задача дня U03, Ср · судья, 19 тестов · уровень: самостоятельно*

## Коротко
Напиши шаблон `checked_at`: верни ссылку на элемент `span` или брось `std::out_of_range` для неверного индекса.
Для `span<const int>` ссылка должна остаться константной.

## Зачем
Одна функция доступа обслуживает и изменяемые буферы, и буферы только для чтения — как выходы и входы ядра.

## Вход и выход
```cpp
template<class T> T& checked_at(std::span<T> v, std::ptrdiff_t index);
```
- Неверный индекс — `index < 0` или `index ≥ v.size()`: брось `std::out_of_range`.
- Верный — верни ссылку на сам элемент: запись через неё меняет `v`.
- Длина — до 1000, индекс — от −1000 до 1001.

| `v` | `index` | результат |
|---|---|---|
| `[3, 4]` | 1 | ссылка на `4`; после `+= 7` — `v = [3, 11]` |
| `[3]` | −1 | `std::out_of_range` |

## Проверь, что понял
Сколько индексов из −1, 0, 2, 3 допустимы при `v.size() == 3`?
