# Верни индекс первого совпадения

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Найди первое вхождение target и верни индекс с нуля. Если совпадений нет, верни -1. Длина до 1024; вход не меняй. Пример: {4,7,7}, target=7 → 1. Не используй find: задача на цикл и ранний return.

## Зачем
Отделять индекс результата от признака отсутствия.

## Вход и выход
```cpp
int first_index(const std::vector<int>& values, int target);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Что вернётся для values={9}, target=8?

## Шаги
1. Для {4,7,7} отметь только первое совпадение.
2. В first_index различи найденный индекс и отсутствие.
3. Проверь совпадение в позиции 0 и пустой вход.

## Готово, когда
Возвращён первый индекс; отсутствие даёт −1. Публичные проверки подтверждают эти свойства.
