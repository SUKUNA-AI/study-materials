# Последний шаг цикла

<!-- паспорт: type=Т05 minutes=20 place="дом или ноут" check=judge level=supported -->

## Коротко
Найди одну ошибку в рабочем цикле: функция должна суммировать числа от одного до n включительно.

## Зачем
Учимся проверять границы на маленьком примере, а не переписывать весь код после первого неверного ответа.

## Вход и выход
```cpp
int sum_to_n(int n);
```
Вход: целое `n`, от 0 до 10000. Выход: сумма `1 + 2 + … + n`; при нуле сумма пуста и равна нулю. В заданном диапазоне результат помещается в int. Примеры: `0 → 0`, `3 → 6`. Сохрани цикл; исправь его условие.

## Проверь, что понял
Чему должна равняться сумма при n = 1?

## Шаги
1. Открой редактор: код уже написан. До запуска выпиши значения i и sum для n = 1.
2. Сравни последовательность обработанных чисел с контрактом. Измени только границу цикла.
3. Повтори трассировку для нуля и трёх. Отправь решение и объясни, почему исправление не добавляет лишнего числа.

## Готово, когда
Открытые и скрытые проверки пройдены. Ты можешь своими словами объяснить граничный случай, а не только показать зелёный вердикт.
