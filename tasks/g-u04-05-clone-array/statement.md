# Скопируй массив в отдельное владение

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Верни независимую копию count элементов. При count=0 data может быть nullptr и результат должен быть пустым unique_ptr. При положительном count доступно ровно count чисел int32; count≤1024. Исходник после возврата может измениться или исчезнуть. Пример: {1,2,3} → отдельный владелец тех же трёх значений. Используй массивную специализацию unique_ptr<int[]>.

## Зачем
Управлять динамическим массивом и отличать глубокую копию от псевдонима.

## Вход и выход
```cpp
std::unique_ptr<int[]> clone_values(const int* data, std::size_t count);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Что должна вернуть clone_values(nullptr, 0)?

## Шаги
1. Различи копию адреса и копию трёх чисел.
2. В clone_values проверь массивную специализацию.
3. Измени исходник после клонирования; проверь count=0.

## Готово, когда
Результат независим; нулевой размер даёт пустого владельца. Публичные проверки подтверждают эти свойства.
