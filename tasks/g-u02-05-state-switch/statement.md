# Сопоставь состояние с именем

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Для State::queued, running и done верни соответственно "queued", "running", "done". В State базовый тип unsigned, коды 0,1,2; другие переданные коды 3…255 дают "unknown". Используй switch с отдельным поведением по умолчанию. Пример: State::running → "running". Не индексируй массив непроверенным кодом.

## Зачем
Обработать все объявленные состояния и защитить случай неизвестного кода.

## Вход и выход
```cpp
std::string state_name(State state);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Что должна вернуть state_name для кода 7, приведённого к State?

## Шаги
1. Выпиши имена трёх объявленных состояний.
2. В state_name выдели поведение для неизвестного кода.
3. Проверь коды 3 и 255.

## Готово, когда
Каждый известный код имеет имя; остальные дают unknown. Публичные проверки подтверждают эти свойства.
