# Выведи шестнадцатеричное число

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Преобразуй uint32 в шестнадцатеричную строку через to_chars. Нужны строчные a…f, без 0x и ведущих нулей; ноль даёт "0". Используй локальный массив из 8 char и границу, возвращённую to_chars. Нулевой терминатор не добавляй и не ищи. Пример: 255 → "ff".

## Зачем
Создать строку из диапазона записанных байтов.

## Вход и выход
```cpp
std::string hexadecimal(std::uint32_t value);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Сколько шестнадцатеричных цифр нужно для UINT32_MAX?

## Шаги
1. Оцени число hex-цифр для максимального uint32.
2. В hexadecimal проверь возвращённую границу to_chars.
3. Проверь 0 и 0xffffffff.

## Готово, когда
Строчные цифры без префикса; длина равна записанным байтам. Публичные проверки подтверждают эти свойства.
