# Дополни свой formatter для точки

<!-- паспорт: type=Т08 minutes=15 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Дополни format в готовой специализации std::formatter<Point>. Формат точки: открывающая скобка, x, запятая и один пробел, y, закрывающая скобка. Дополнительных спецификаторов у Point нет. Обёртка format_point использует std::format("{}", Point{x,y}); её путь сохрани. Пример: (3,-4) → "(3, -4)". Полный синтаксис специализации уже дан; шаблоны с нуля писать не требуется.

## Зачем
Применить formatter на небольшом собственном типе без изучения шаблонного метапрограммирования.

## Вход и выход
```cpp
std::string format_point(int x, int y);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Куда специализация std::formatter<Point> должна записывать текст точки?

## Шаги
1. Предскажи точные байты для Point{3,−4}.
2. Дополни format готового formatter, сохрани обёртку.
3. Проверь нули и отрицательные координаты.

## Готово, когда
Формат ровно (x, y); вызов идёт через std::format. Публичные проверки подтверждают эти свойства.
