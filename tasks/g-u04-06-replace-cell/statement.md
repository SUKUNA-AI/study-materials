# Замени объект с правильным временем жизни

<!-- паспорт: type=Т10 minutes=10 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
Замени прежний Cell новым Cell(value), даже если числовые значения совпадают. Старый объект должен быть уничтожен ровно один раз; пустой owner допустим. Значения в пределах ±100000. Счётчики конструктора и деструктора предоставляет Cell. Пример: Cell(4) → новый Cell(7), один старый объект уничтожен. Обработку исключения выделения памяти вручную писать не требуется.

## Зачем
Различать изменение содержимого и замену времени жизни объекта.

## Вход и выход
```cpp
void replace_cell(std::unique_ptr<Cell>& owner, int value);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Сколько новых Cell создаётся при замене значения 4 на такое же 4?

## Шаги
1. Запиши счётчики Cell перед заменой.
2. В replace_cell проследи судьбу прежнего объекта.
3. Проверь замену на равное числовое значение.

## Готово, когда
Создан новый Cell; старый уничтожен ровно один раз. Публичные проверки подтверждают эти свойства.
