# Число блоков без переполнения

*Реализуй (Т10) · задача дня U01, запас (Вт) · судья, 16 тестов · уровень: самостоятельно*

## Коротко
Допиши `block_count(n, block)`: верни, сколько блоков по `block` элементов покроют `n` элементов.
Ответ должен быть верным вплоть до `n = UINT64_MAX`.

## Зачем
Так считается размер сетки перед запуском ядра; беззнаковое переполнение UBSan не ловит.

## Вход и выход
```cpp
std::uint64_t block_count(std::uint64_t n, std::uint64_t block);
```
- `n` — от 0 до `UINT64_MAX`, `block` — от 1 до 1024.
- Нельзя: числа с плавающей точкой.

| `n` | `block` | ответ |
|---|---|---|
| 0 | 32 | 0 |
| 65 | 32 | 3 |

## Проверь, что понял
Сколько блоков нужно при `n = 2⁶⁴ − 1` и `block = 2`? Запиши число до кода.
