# Открой вход и передай владение дескриптором

<!-- паспорт: type=Т10 minutes=20 place="Linux-ноутбук без GPU; учебный Ubuntu WSL, не рабочий archlinux" check=judge level=supported -->

## Коротко
Открой существующий путь только для чтения и с O_CLOEXEC. Верни неотрицательный дескриптор: владение получает вызывающий код, функция его не закрывает. При ошибке немедленно сохрани errno и передай его готовой fail_open(saved,path). Не создавай и не обрезай файл. Дескриптор 0 допустим. Пример: файл "abc" → открытый дескриптор, через который читаются ровно три байта.

## Зачем
Связать результат системного вызова, флаги открытия и передачу владения.

## Вход и выход
```cpp
int open_input(const char* path);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Можно ли считать дескриптор 0 успешным результатом open_input?
Зачем при открытии указывается O_CLOEXEC?

## Шаги
1. Различи открытие для чтения и создание файла.
2. В open_input проверь передачу дескриптора и сохранение errno.
3. Проверь отсутствие пути и допустимый дескриптор 0.

## Готово, когда
Нет создания/обрезки; CLOEXEC установлен; ошибка сохранена. Публичные проверки подтверждают эти свойства.
