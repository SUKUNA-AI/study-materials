# Сначала копия, потом замена

*Реализуй (Т10) · задача дня U03, запас (Вт) · судья, 19 тестов · уровень: самостоятельно*

## Коротко
Замени содержимое `dst` копией `src` со строгой гарантией исключений (strong exception safety).
Если копирование элемента бросит, `dst` должен остаться прежним, а исключение — уйти наружу.

## Зачем
Сбой посреди обновления параметров ядра не должен портить рабочую копию.

## Вход и выход
```cpp
// solution.h: бросает std::bad_alloc, когда index == fail_after
inline int copy_item(int value, std::size_t index, std::size_t fail_after);
inline void replace_checked(std::vector<int>& dst, std::span<const int> src,
                            std::size_t fail_after);
```
- Каждый элемент копируй через `copy_item(src[i], i, fail_after)`.
- После успеха `dst` равен `src`. Длины — до 1000.
- `src` может смотреть в сам `dst`: стенд передаёт `dst` без первого элемента.

| `dst` | `src` | сбой | `dst` после |
|---|---|---|---|
| `[8, 9]` | `[1, 2, 3]` | нет | `[1, 2, 3]` |
| `[8, 9, 10]` | `dst` без первого | нет | `[9, 10]` |

## Проверь, что понял
`dst = [8, 9]`, `src = [1, 2, 3]`, сбой при копировании элемента с индексом 1. Каким станет `dst`?
