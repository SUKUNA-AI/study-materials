# Просуммируй строки плоской таблицы

<!-- паспорт: type=Т10 minutes=15 place="ноутбук или ПК; GPU не нужен" check=judge level=supported -->

## Коротко
values хранит таблицу построчно: подряд идут все cols элементов первой строки, затем второй. Верни сумму каждой строки. rows и cols находятся в [0,32], size()==rows*cols. Элементы int32, суммы int64. При cols=0 каждая существующая строка имеет сумму 0. Пример: таблица 2×3 с {1,2,3,4,5,6} → {6,15}.

## Зачем
Связать два вложенных цикла с плоской адресацией.

## Вход и выход
```cpp
std::vector<std::int64_t> row_totals(const std::vector<int>& values, std::size_t rows, std::size_t cols);
```
Объявления и вспомогательные типы находятся в `solution.h`. Не меняй интерфейс; результат передаётся стенду, а не печатается из твоей функции.

## Проверь, что понял
Какое смещение имеет начало строки с индексом 2 при cols=3?

## Шаги
1. Разметь плоский массив 2×3 границами строк.
2. В row_totals сопоставь строку с её участком.
3. Проверь rows=2, cols=0.

## Готово, когда
Число сумм равно rows; нулевые столбцы дают нулевые суммы. Публичные проверки подтверждают эти свойства.
