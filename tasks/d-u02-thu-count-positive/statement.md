# Считаем положительные элементы

<!-- паспорт: type=Т10 minutes=20 place="дом или ноут" check=judge level=supported -->

## Коротко
Напиши короткую функцию по готовому плану: посчитай элементы массива, строго большие нуля.

## Зачем
Это первая самостоятельная сборка знакомых действий: счётчик, цикл и условие. Новые контейнеры или шаблоны не нужны.

## Вход и выход
```cpp
std::size_t count_positive(const int* values, std::size_t n);
```
`n` — от 0 до 1024. При `n > 0` указатель values ведёт к n доступным числам int. При `n = 0` он может быть nullptr: ничего не читай. Вход не меняй. Верни количество положительных чисел, не их сумму. Примеры: `[-2,0,5] → 1`, `[] → 0`.

## Проверь, что понял
Сколько положительных чисел в массиве [-4, 0, 2, 2]?

## Шаги
1. Открой редактор. Перед началом разбери похожую функцию count_negative в уроке: здесь меняется проверяемое свойство.
2. Заведи счётчик. Обойди индексы от нуля, не достигая n. Увеличивай счётчик только при нужном знаке.
3. Проверь пустой массив, нули и повторяющиеся положительные числа. Отправь решение; готовый main не нужен.

## Готово, когда
Открытые и скрытые проверки пройдены. Ты можешь своими словами объяснить граничный случай, а не только показать зелёный вердикт.
