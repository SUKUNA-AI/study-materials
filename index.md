# Материалы курса

Здесь лежит то, что нужно для работы без портала: читаемый материал стартовой недели, условия и публичные
тесты первых задач и каталог всей программы. **Офлайн-полнота всех 52 недель не заявляется**: для остальных
недель материал открывается на портале (ссылки ниже). Публичные тесты — только открытая часть проверки;
прохождение их не означает прохождение серверной проверки.

## Как открыть занятие

- Занятие недели: `https://study.sukuna.tech/week?unit=U01` (подставь номер недели).
