# Перед задачей: представление и собственная строка

5 минут внутри двадцатиминутной задачи U05.D1, не дополнительное чтение.
После U02.T8 и U02.T11: сначала вспомни, кто владеет символами. Затем разбери
пример с префиксом; в задаче потребуется суффикс и другая граница.

```cpp
#include <cassert>
#include <string>
#include <string_view>
int main() {
    std::string source{"ab\0cd", 5};
    std::string_view borrowed{source};
    std::string owned{borrowed.substr(0, 3)};
    source[0] = 'X';
    assert(borrowed[0] == 'X');
    assert(owned[0] == 'a' && owned.size() == 3);
}
```

`borrowed` смотрит на существующий буфер; копии символов у него нет. `substr`
создаёт ещё одно представление. Конструктор `std::string` из представления уже
копирует символы с их длиной, включая внутренний нулевой байт. Изменение источника
не меняет `owned`. Не используй представление после уничтожения источника.

Прогноз R1 до запуска: какую длину имел бы результат, если заменить конструирование
`owned` на `std::string owned{borrowed.data()};`? Почему это другой контракт?

Закрой пример и открой редактор `own_suffix`. В задаче не нужно копировать всю
строку перед выбором суффикса. После 5 минут переходи к коду; не читай главу заново.
