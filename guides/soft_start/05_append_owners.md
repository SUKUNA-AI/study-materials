# Перед задачей: пустой владелец и пустой вектор — не одно

5 минут внутри двадцатиминутной задачи U06.D3. Сначала должны быть пройдены
U04.T8, U05.T10 и U05.D3 (`take_job`). Здесь переносится один элемент, не вся очередь.

```cpp
#include <cassert>
#include <memory>
#include <utility>
#include <vector>
int main() {
    std::vector<std::unique_ptr<int>> source;
    source.push_back(std::make_unique<int>(23));
    auto held = std::move(source.front());
    assert(source.size() == 1 && !source.front());
    source.clear();
    assert(source.empty() && *held == 23);
}
```

Контейнер хранит элемент типа `unique_ptr`. После перемещения владелец пуст, но
сам элемент контейнера существует. `clear()` уничтожает элементы, а не объект,
уже переданный `held`. При переносе между разными векторами рост приёмника может
изменить адреса его элементов-владельцев; адреса выделенных ими объектов остаются
прежними. Не разыменовывай пустого владельца.

Прогноз R4: если до `clear()` вызвать `source.push_back(nullptr)`, сколько элементов
будет в `source`? Сколько из них владеют объектами?

Закрой пример. В задаче самостоятельно составь цикл с сохранением порядка и
проверь постусловия обоих векторов. Справка по карте: Грегуар, гл. 7, PDF 460–466;
гл. 18, 1148–1160. Первоисточник передачи: [unique_ptr](https://eel.is/c++draft/unique.ptr.single.ctor).
